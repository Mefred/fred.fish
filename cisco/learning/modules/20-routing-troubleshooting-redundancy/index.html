Routing Troubleshooting and First-Hop Redundancy

Troubleshoot route selection and end-to-end paths, and understand first-hop redundancy.

CCNA 200-301IP CONNECTIVITY3 QUESTION QUIZ

Learning objectives

  • Explain the purpose and scope of Routing Troubleshooting and First-Hop Redundancy.
  • Identify important protocols, roles, fields, and terminology.
  • Apply the concept to a practical network scenario.
  • Use IOS XE commands to verify operational behavior.

1. Core concepts

Start with endpoint IP, mask, and gateway. Verify local link and VLAN. Check router interface state and connected routes. Inspect the routing table, next-hop reachability, ACLs, and return route. Use ping with progressively distant targets and traceroute to identify where forwarding stops.

2. How it works

First-Hop Redundancy Protocols let multiple routers present a shared virtual gateway IP/MAC. Hosts use that virtual gateway while routers coordinate forwarding. HSRP is Cisco-developed with active/standby roles; VRRP is an open standard with master/backup terminology. Tracking can reduce priority when an upstream path fails.

3. Worked example

Two routers share virtual gateway 192.168.10.1 for VLAN 10. Hosts use it as default gateway. R1 is active and R2 standby. If R1 fails, R2 assumes the virtual gateway role after convergence, so hosts need not change their configured gateway.

IOS XE commands and verification

Syntax and feature availability can vary by device family and software release. Confirm platform support before applying configuration.

show standby brief
show standby vlan 10
show vrrp brief
show ip route
ping <next-hop>
traceroute <destination>

Common mistakes and troubleshooting

  • Check physical and interface state before changing higher-layer settings.
  • Verify both ends agree on addressing, VLAN, encapsulation, and protocol parameters.
  • Use operational show commands; configured text alone does not prove a feature is working.
  • Change one variable at a time and verify the result.

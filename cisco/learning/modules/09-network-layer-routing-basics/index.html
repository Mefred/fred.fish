The Network Layer and Routing Basics

Understand IP packets, routing tables, next hops, longest-prefix match, and hop limits.

CCNA 200-301IP CONNECTIVITY3 QUESTION QUIZ

Learning objectives

  • Explain the purpose and scope of The Network Layer and Routing Basics.
  • Identify important protocols, roles, fields, and terminology.
  • Apply the concept to a practical network scenario.
  • Use IOS XE commands to verify operational behavior.

1. Core concepts

The Network Layer provides logical addressing and delivery across networks. IP is connectionless and best-effort: it does not guarantee delivery, ordering, or retransmission. Routers inspect destination IP addresses and consult routing tables to select an outgoing interface and/or next hop.

2. How it works

Routers use longest-prefix match: among matching routes, the most specific prefix wins. If prefixes are equal, route preference and metrics influence selection. Cisco administrative distance compares route sources; protocol metrics compare paths within a protocol. A default route 0.0.0.0/0 or ::/0 is fallback.

3. Worked example

With routes 10.0.0.0/8, 10.1.0.0/16, and 0.0.0.0/0, destination 10.1.2.3 matches all three but /16 wins. IPv4 TTL and IPv6 Hop Limit are decremented by routers; zero causes discard.

IOS XE commands and verification

Syntax and feature availability can vary by device family and software release. Confirm platform support before applying configuration.

show ip route
show ip route 10.1.2.3
show ipv6 route
show ip interface brief

Common mistakes and troubleshooting

  • Check physical and interface state before changing higher-layer settings.
  • Verify both ends agree on addressing, VLAN, encapsulation, and protocol parameters.
  • Use operational show commands; configured text alone does not prove a feature is working.
  • Change one variable at a time and verify the result.

Network Devices and Topologies

Identify infrastructure device roles and compare physical and logical designs.

1. Core concepts

A hub is a Layer 1 repeater. A bridge or Layer 2 switch forwards frames using MAC addresses. A router forwards IP packets between networks. A multilayer switch can switch and route. A firewall enforces traffic policy; an access point bridges wireless clients onto a wired LAN.

2. How it works

Physical topology describes actual cabling and device connections; logical topology describes traffic flow and segmentation. Star, mesh, bus, and ring are common patterns. Enterprise campuses often use access, distribution, and core roles; WANs connect geographically separated networks.

3. Worked example

A small office may connect an ISP handoff to a router/firewall, a LAN switch for wired devices, and APs on access ports. The router provides WAN connectivity and a default gateway; the switch provides local Layer 2 connectivity.

IOS XE commands and verification

Syntax and feature availability can vary by device family and software release. Confirm platform support before applying configuration.

show cdp neighbors
show lldp neighbors
show interfaces status
show ip interface brief

Common mistakes and troubleshooting

  • Check physical and interface state before changing higher-layer settings.
  • Verify both ends agree on addressing, VLAN, encapsulation, and protocol parameters.
  • Use operational show commands; configured text alone does not prove a feature is working.
  • Change one variable at a time and verify the result.

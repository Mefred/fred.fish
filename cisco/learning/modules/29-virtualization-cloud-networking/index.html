Network Virtualization and Cloud Networking

Understand server virtualization, containers, VRFs, cloud deployment models, and virtual network segmentation.

1. Core concepts

Server virtualization uses a hypervisor to run multiple virtual machines on shared physical hardware. Type 1 hypervisors run directly on hardware; Type 2 hypervisors run on a host operating system. Containers isolate applications while sharing the host OS kernel, making them lighter than full VMs but with a different isolation model.

2. How it works

Network virtualization creates logical networks over shared infrastructure. VLANs segment Layer 2 broadcast domains. VRFs maintain separate Layer 3 routing tables on one router or switch. Overlay technologies can build virtual networks over an underlay IP fabric. Cloud deployment models include public, private, hybrid, and community cloud. SaaS, PaaS, and IaaS describe service models.

3. Worked example

A company may place production and lab routing into separate VRFs on one router so identical or overlapping address spaces remain isolated. A hybrid cloud connects on-premises resources with public cloud services using secure connectivity and controlled routing.

IOS XE commands and verification

Syntax and feature availability can vary by device family and software release. Confirm platform support before applying configuration.

show vrf
show ip route vrf <name>
show interfaces status
show vlan brief

Common mistakes and troubleshooting

  • Check physical and interface state before changing higher-layer settings.
  • Verify both ends agree on addressing, VLAN, encapsulation, and protocol parameters.
  • Use operational show commands; configured text alone does not prove a feature is working.
  • Change one variable at a time and verify the result.

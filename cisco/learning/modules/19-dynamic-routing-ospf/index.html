Dynamic Routing and OSPF

Understand dynamic routing and configure single-area OSPF to exchange routes automatically.

Learning objectives

  • Explain the purpose and scope of Dynamic Routing and OSPF.
  • Identify important protocols, roles, fields, and terminology.
  • Apply the concept to a practical network scenario.
  • Use IOS XE commands to verify operational behavior.

1. Core concepts

Dynamic routing protocols exchange reachability information so routers learn routes automatically. Static routing is simple but requires manual maintenance. OSPF is a link-state IGP; EIGRP is an advanced distance-vector protocol in Cisco environments; BGP is an interdomain path-vector protocol.

2. How it works

OSPF routers discover neighbors with Hello packets, exchange link-state information, build a link-state database, and run the Shortest Path First algorithm. Area 0 is the backbone. Adjacencies require compatible area, subnet, timers, authentication, and network type. Process IDs are locally significant.

3. Worked example

R1 has 10.0.12.1/30 to R2 and LAN 192.168.1.0/24. Under router ospf 1, advertise 10.0.12.0 0.0.0.3 area 0 and 192.168.1.0 0.0.0.255 area 0.

IOS XE commands and verification

Syntax and feature availability can vary by device family and software release. Confirm platform support before applying configuration.

router ospf 1
 router-id 1.1.1.1
 network 10.0.12.0 0.0.0.3 area 0
 network 192.168.1.0 0.0.0.255 area 0
show ip ospf neighbor
show ip route ospf
show ip ospf database

Common mistakes and troubleshooting

  • Check physical and interface state before changing higher-layer settings.
  • Verify both ends agree on addressing, VLAN, encapsulation, and protocol parameters.
  • Use operational show commands; configured text alone does not prove a feature is working.
  • Change one variable at a time and verify the result.

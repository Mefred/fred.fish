QoS and Network Monitoring Services

Understand classification, marking, queuing, shaping, policing, time synchronization, monitoring, and logging.

Learning objectives

  • Identify important protocols, roles, fields, and terminology.
  • Apply the concept to a practical network scenario.
  • Use IOS XE commands to verify operational behavior.

1. Core concepts

QoS manages congestion and prioritizes traffic. Classification identifies traffic by application, address, protocol, or policy. Marking records treatment intent using fields such as IP DSCP or 802.1p CoS. Queuing schedules traffic. Policing enforces a rate and may drop or remark excess traffic. Shaping buffers traffic to smooth its output rate.

2. How it works

QoS does not create bandwidth. Trust boundaries determine whether endpoint markings are accepted. NTP synchronizes clocks so events can be correlated. SNMP allows monitoring systems to query agents and receive traps or informs. SNMPv3 adds authentication and privacy. Syslog centralizes device event messages.

3. Worked example

If voice and bulk backups compete for a WAN link, classify and mark voice traffic, place it in an appropriate low-latency queue, and shape or police other traffic according to policy. Monitor queue drops and interface utilization. Ensure device clocks and log timestamps are synchronized.

IOS XE commands and verification

Syntax and feature availability can vary by device family and software release. Confirm platform support before applying configuration.

show policy-map interface gi0/0/0
show ntp status
show logging
show snmp
show interfaces counters errors

Common mistakes and troubleshooting

  • Check physical and interface state before changing higher-layer settings.
  • Verify both ends agree on addressing, VLAN, encapsulation, and protocol parameters.
  • Use operational show commands; configured text alone does not prove a feature is working.
  • Change one variable at a time and verify the result.

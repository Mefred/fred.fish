CISCO / QUICK LOOKUP

IOS XE reference

A concise command and configuration reference for common Cisco IOS XE workflows. Examples are starting points; interface names and feature availability depend on the device.

Platform scope

These examples target IOS XE CLI conventions. They are not a promise that every command exists on every IOS XE device or software release.

Device inspection

EXEC MODE

System and platform

Identify the software version, hardware, uptime, and installed resources.

show version
show inventory
show platform
show clock

Interfaces and addressing

Quickly inspect interface state and IP configuration.

show ip interface brief
show interfaces
show interfaces description
show running-config | section interface

Switching and VLANs

Inspect VLAN membership, trunk state, and learned MAC addresses.

show vlan brief
show interfaces trunk
show mac address-table

Routing and connectivity

Check routes and test reachability from the device.

show ip route
show ip protocols
ping 192.0.2.1
traceroute 192.0.2.1

Common configuration pattern

CONFIGURATION MODE

Configure an interface

Example template using a documentation-only address. Replace the interface and address values for the actual lab.

configure terminal
interface GigabitEthernet1/0/1
 description Example connection
 ip address 192.0.2.1 255.255.255.0
 no shutdown
end
copy running-config startup-config
